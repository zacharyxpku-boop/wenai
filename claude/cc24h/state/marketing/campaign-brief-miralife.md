# Campaign Brief -- MiraLife -- 2026-03-26

## Source
Product stage: P0 (closest to revenue, MVP complete, pre-launch)
Council guidance: GO for cold-start, validate payment at 9.9, hepan is primary viral mechanic

## Objective
在 7 天内通过私域 + 小红书种草获得首批 50 个真实用户，验证"用户是否愿意完成全部引擎并分享结果"。

## KPI
- Primary: 50 个完成至少 1 个引擎的真实用户
- Secondary: 10 个自然分享（非被要求的分享行为）
- Stretch: 3 个付费转化（9.9 深度报告）

## Timeline
- Day 1-2: 私域首发（朋友圈 + 50人内测群）
- Day 3-5: 小红书 3 条种草内容发布
- Day 5-7: 合盘裂变启动（邀请伴侣/闺蜜测试）
- Day 7: 首轮复盘

## Target User
- 18-30 岁女性为主，对 MBTI/星座有基本认知
- 刷小红书时会停下来看"测试类"内容
- 会把有趣的测试结果截图发给闺蜜/男朋友
- 对"算命"有好奇心但对"伪科学"标签有戒心
- 核心场景：无聊刷手机 → 看到有趣测试 → 试一下 → 看到结果很准 → 截图/分享

## Core Message
"不是算命，是用四面镜子照见真实的你"

## Primary Channel
私域（朋友圈 + 微信群） → 小红书种草

## Content Pillars
1. 雷达图视觉冲击 — "你的八维人生图谱长这样"
2. 三面自画像 — "MBTI说我外向，八字说我内敛，到底哪个是真的我？"
3. 合盘配对 — "测测你和TA的缘分指数"

## Key Messaging
- Headline: "你的三面镜子，照出不同的你"
- Subheadline: "当 MBTI、八字、塔罗同时指向一个方向——那就是真的你"
- CTA: "免费测一下，看看你的八维图谱"

## Automation Level
- 内容生成: 全自动
- 素材 Brief: 全自动
- 发布: 人工确认后发布（复制粘贴到平台）
- 裂变机制: 产品内自动（分享链接已内置）
- 数据收集: 半自动（Supabase 自动 + 群内反馈人工记录）

## Off-Limits
- 不做付费投放（先验证自然增长）
- 不承诺"准确预测未来"
- 不用"AI驱动""智能洞察"等禁止词
- 不做微商式群发轰炸
