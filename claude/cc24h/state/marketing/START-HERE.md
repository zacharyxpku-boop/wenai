## 出了问题怎么办

| 情况 | 怎么办 |
|---|---|
| 小红书发了没人看 | 删掉，换个标题和封面，第二天重发 |
| 群里没人说话 | 发一个有趣的测试结果截图 + 提问 |
| 有人说"不准" | 打开 `qa-pack` → 异议处理 → "这个准吗" |
| 有人说"像AI生成的" | 打开 `qa-pack` → 异议处理 → "AI生成" |
| 没人做合盘 | 直接私聊 3 对情侣："你俩试试这个合盘" |
| 没人付 9.9 | 在群里问："如果完整版包含XX，你觉得值多少？" |
| 小红书被限流 | 检查是否用了敏感词（算命/占卜/迷信），改掉重发 |
| 我今天没时间 | 跳过就好，明天继续。节奏比频率重要 |
