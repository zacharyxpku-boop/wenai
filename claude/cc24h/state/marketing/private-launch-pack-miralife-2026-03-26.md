## 3. 9图顺序建议

| 序号 | 内容 | 设计要点 |
|------|------|----------|
| **1（Hook图）** | 一张视觉冲击力强的雷达图特写，形状明显不对称，配文字"这是我，你的长什么样？" | 底色用深色（深墨绿/藏蓝），雷达图线条用亮色（金/橘），让人好奇自己的形状。不要用紫蓝渐变。 |
| **2** | 四个引擎图标并排：MBTI脑图标 + 八字阴阳符 + 塔罗牌背面 + 星座星盘，下方一行字"四面镜子，四个角度" | 图标风格统一，手绘质感优于扁平风 |
| **3** | 产品首页截图：输入生日+选择的界面，突出"只需要30秒" | 真实截图，标注操作步骤 |
| **4** | 八维雷达图完整展示，标注八个维度名称，配文"每个人的形状都独一无二" | 用一个真实用户案例（脱敏），让人想对比 |
| **5** | 某一个维度的详细解读截图，比如"情感表达方式"维度，展示具体文字描述 | 文字要能看清，让人感受到内容深度 |
| **6** | 两张雷达图叠在一起的合盘效果图，标注"互补区"和"冲突区" | 用不同颜色区分两个人，重叠区域高亮 |
| **7** | 3-4条真实用户反馈截图（内测群里收集的），比如"被戳到了""和对象看完居然没吵架" | 聊天截图风格，真实感 > 设计感 |
| **8** | ¥9.9深度报告的内容预览：目录页或某一页精华内容，让人感受到付费版的价值差异 | 只露一角，制造好奇 |
| **9（CTA图）** | 二维码/链接，配文案"扫一下，30秒看见自己" + "免费 · 不用注册 · 结果可以分享给朋友" | 字要大，信息要少，行动门槛要低 |
