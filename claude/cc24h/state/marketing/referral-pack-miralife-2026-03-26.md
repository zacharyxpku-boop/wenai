## 1. Share Trigger Design — 什么时候弹分享

### 触发时机（按情绪峰值排序）

| 时机 | 情绪状态 | 触发动作 |
|------|---------|---------|
| **P0: 合盘结果揭晓瞬间** | 惊讶+好奇（"居然是相克？！"） | 结果卡自动生成，底部出现「发给TA看看」按钮 |
| **P1: 发现矛盾维度** | 困惑+兴奋（"感情维度99但沟通维度23？"） | 该维度卡片右上角出现分享icon，点击生成单维度对比图 |
| **P2: 五行轮盘动画播完** | 视觉满足+炫耀欲 | 轮盘下方出现「这张图太好看了，存一张」→ 保存即带水印链接 |
| **P3: 看完深度解读后** | 认同感（"说得也太准了"） | 底部浮现「测测你和别人的缘分」→ 开启新合盘 |

### 设计原则

- **不弹窗打断**：所有分享入口是页面自然元素，不是弹窗
- **先给价值再要分享**：用户必须先看到完整结果，分享按钮才可见
- **分享 = 社交货币**：分享的不是"广告"，是"我和TA的故事"
- **给借口而非请求**：不说"分享给好友"，说"让TA也看看自己那边的结果"

### 情绪曲线设计

```
情绪
 ↑
 █                          ████ ← P0: 结果揭晓（最高峰）
 █                    ██████
 █               █████           ██ ← P1: 矛盾维度
 █          █████
 █     █████                        █ ← P2: 轮盘动画
 █ ████
 █                                     █ ← P3: 深度解读
 ─────────────────────────────────────→ 时间
   输入   等待   揭晓   细看   解读
```

**核心规则：只在波峰出现分享入口，波谷绝不打扰。**

## 5. Receiver Experience Spec — 接收者体验

### 点击链接后的流程

```
Step 0: 点击链接（微信内/浏览器）
  ↓
Step 1: 落地页（3秒内加载完）
  显示：
  - 发送者的类型卡片（模糊处理，制造悬念）
  - "XX 想看你俩的合盘结果"
  - 大按钮：「开始测试，30秒搞定」
  - 小字：不用注册，不用下载
  ↓
Step 2: 快速输入（30秒内完成）
  - 生日（日期选择器，3次点击）
  - 出生时辰（可选，不知道可跳过）
  - MBTI（4道快速二选一，或直接选已知类型）
  ↓
Step 3: 结果生成动画（5秒）
  - 五行轮盘旋转
  - 两人元素碰撞动画
  - 缘分指数跳动揭晓
  ↓
Step 4: 完整结果页
  - 双方都能看到完整结果
  - 发送者收到推送："TA填完了，来看你俩的完整合盘"
```

### 关键体验指标

| 指标 | 要求 |
|------|------|
| 从点击到开始填写 | ≤ 10秒 |
| 填写完成时间 | ≤ 30秒 |
| 需要注册吗 | 不需要。填完即看结果。 |
| 需要下载吗 | 不需要。纯网页。 |
| 接收者能看到发送者结果吗 | 填完之前：看到模糊版（类型名+模糊头像）。填完之后：完整双人结果。 |
| 填完后会提示分享吗 | 会。见下方 §6 Re-share CTA。 |
| 链接有效期 | 7天。过期后提示"重新发起合盘"。 |

### 防流失设计

- **微信内打开**：自动适配微信浏览器，不跳转外部
- **加载慢**：骨架屏 + "正在计算你俩的五行关系..." 文案
- **中途退出**：已填信息缓存在本地，回来继续
- **不知道出生时辰**：可跳过，结果页标注"加上时辰会更准"作为二次触发

### 裂变链路

```
A 发起 → B 完成 → B 看到结果
                     ↓
              B 保存图片（带短链）→ B 的朋友圈/群 → C 点击
                     ↓
              B 发起新合盘 → 邀请 C → C 完成 → C 看到结果
                     ↓                              ↓
              B 点"完整个人报告"              C 保存/发起新合盘 → D
                     ↓
              B 完成更多引擎 → 新分享素材产生
```

### 关键：让 B→C 的动机不同于 A→B

| 环节 | 动机 | 文案方向 |
|------|------|---------|
| A→B | "我想知道我和TA配不配" | 好奇心驱动 |
| B→C | "我发现一个好玩的，你也来" | 分享欲驱动 |

| C→E | "我的结果比你的离谱" | 竞争/炫耀驱动 |

> **五行相克但缘分分数很高**

## 10. 风控提醒

- 不暗示"算命可以预测未来"
- 不说"你们不配"——所有相克结果都给正面解读路径
- 不收集手机号/身份证——只要生日+时辰（可选）+MBTI
- 分享图片不含真实生日信息——只显示类型名和分数
- 链接不含明文个人数据——全部编码处理
- 合盘结果不做永久存储——7天后数据清除，需重测
