- Purpose: 展示个性化八维雷达图，视觉冲击力第一
- Type: screenshot + text overlay

- Platform: 小红书封面

- Key Visual Element: 雷达图本身——不规则的形状比圆形更有辨识度
- Trust Signal: 真实产品截图，不是 mockup

## Asset 3: 合盘缘分卡（小红书 Post 3 封面 + 裂变分享图）

- Purpose: 展示双人配对结果，引发"我也想测"的冲动
- Type: 设计图
- Dimensions: 1080 x 1440 (小红书) + 1080 x 1920 (朋友圈/分享)
- Platform: 小红书 + 朋友圈 + 私聊转发
- Layout Brief:
  - 上半部分: 两个圆形区域左右排列
    - 左: "你" + 类型名 (如"自由烈火型") + 元素图标
    - 右: "TA" + 类型名 (如"深水静流型") + 元素图标
  - 中间: 五行交互线（相生用绿色，相克用红色）
  - 下半部分: 缘分指数大数字 (如 "78%")
  - 底部: 悬念句 "有一个维度你们完全相反..." + CTA
- Text Overlay:
  - "你和TA的缘分图谱" (顶部, 白色)
  - 缘分指数 "78%" (中间, 大字, 紫色 #8B5CF6)
  - "免费测你们的" (底部 CTA, 小字)
- Background: #0A0E1A
- Key Visual Element: 缘分指数的大数字 — 0.5 秒内抓住注意力
- Trust Signal: 五行交互线显示具体分析维度，不是随机数字
- Do NOT: 用爱心/粉红色调、用真人照片、把它做成情人节贺卡
