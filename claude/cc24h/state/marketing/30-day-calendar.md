# 应急预案（Contingency Playbook）

> 遇到问题不要慌，按以下方案执行

---

## 场景1：帖子发了24小时0互动

**诊断**：
- 检查发布时间是否在高峰期
- 检查标题是否有足够悬念
- 检查封面图是否有吸引力

**行动**：
1. 不要删帖（小红书对删帖敏感）
2. 换一个标题重新发一篇（同样内容不同标题，间隔24小时）
3. 用 `content-packs/xhs-miralife-2026-03-26.md` 里的标题变体做A/B测试
4. 在其他帖的评论区互动引流
5. 在群里分享这篇内容获取初始互动

---

## 场景2：有人问尖锐问题（"这不就是骗钱的吗""封建迷信"）

**行动**：
1. 不要删评论（删评引发更大争议）
2. 回复时态度坦诚，不防守
3. 使用 `qa-pack-miralife-2026-03-26.md` → 第二部分 → 异议处理话术
4. 核心句式："不做预测，更像是用多个维度帮你看清自己。准不准你说了算，反正免费试。"
5. 如果对方持续攻击 → 不继续回应，让其他用户的正面评论自然覆盖

---

## 场景3：微信群沉默了（24小时无人说话）

**行动**：
1. 不要发"怎么没人说话了"（越说越冷）
2. 发一个具体的互动问题："今天看到一个ISFJ的雷达图居然是完美圆形，你们有ISFJ吗？来验证一下"
3. 如果还是没人 → 私聊群里最活跃的2-3个人，请TA们帮忙在群里互动
4. 如果连续3天冷 → 减少群消息频率到1条/天，把精力转到小红书
5. 考虑在群里发"限时福利"激活（如"今天前3个做合盘的送深度报告"）

---

## 场景4：小红书帖子被限流/标记

**诊断**：
- 检查是否使用了敏感词（参考 `content-packs/xhs-miralife-2026-03-26.md` → 附录 → 敏感词规避清单）
- 检查是否有链接/二维码/联系方式
- 检查是否被举报

**行动**：
1. 不要修改已发的帖子（修改后重新审核更严格）
2. 下一篇帖子避免同样的词
3. 所有"算命""占卜""风水""迷信"词汇替换为"测试""分析""对比""镜子"
4. 链接只在评论区引导"私信"或"搜MiraLife"
5. 如果账号被限 → 暂停2-3天再发，不要连续踩红线

---

## 场景5：没人做合盘

**诊断**：
- 合盘入口是否够明显？
- 用户是否理解合盘是什么？
- 是否缺少合盘场景激发？

**行动**：
1. 在群里做示范：自己发起一个合盘，截图整个过程
2. 降低门槛话术："不一定要跟对象，跟闺蜜也可以，跟爸妈也行"
3. 创造竞争："看看谁的合盘缘分指数最高"
4. 用 `referral-pack-miralife-2026-03-26.md` → 第3.3节 所有场景的话术轮流试
5. 如果还是不行 → 说明合盘功能体验有问题，优先修产品

---

## 场景6：没人愿意付 9.9

**诊断**：
- 用户是否知道有付费选项？
- 付费页面的价值展示是否清楚？
- 免费版是否已经"给太多"了？

**行动**：
1. **第一步**：私聊问3个活跃用户"你看到深度报告了吗？什么感觉？不买的原因是什么？"
2. **第二步**：在群里做一次"深度报告内容预览"——截图报告的2-3段精华（要有信息增量，不是重复免费版的）
3. **第三步**：给5个核心用户免费解锁深度报告，请TA们在群里说感受
4. **第四步**：如果上述都不行，考虑调价到 6.9 或 4.9 试水
5. **第五步**：如果调价也不行 → 说明付费内容本身不够有吸引力，需要重新设计深度报告内容
6. 参考 `qa-pack-miralife-2026-03-26.md` → Q2 和 Q5 的回复话术

---

## 场景7：产品出 Bug，用户在群里反馈

**行动**：
1. 立刻回复："收到！我现在就去看，马上修"（不要拖）
2. 30分钟内给进展："正在修，预计X小时内搞定"
3. 修完后@反馈的人："已经修好了，你再试试，抱歉！"
4. 把这个bug记录到产品迭代清单
5. 不要说"这是已知问题"（让人觉得不重视）

---

## 场景8：有人抄袭你的内容/产品

**行动**：
1. 截图留证
2. 不在公开场合骂战
3. 加速自己的内容产出，用速度拉开差距
4. 如果对方体量小 → 忽略，专注自己
5. 如果对方体量大 → 考虑差异化，强化"原创四维交叉验证"定位
