# Clico AI Video Dashboard

## What This Is

A full-stack SaaS platform that lets merchants self-serve AI video production: upload product photos, select reference viral videos from an auto-curated library, and receive UGC-style TikTok/Reels videos generated by cloning proven viral structures onto their products. Internal operators manage production queues, quality control, and client accounts. Think "Canva for TikTok product videos" powered by AI video generation.

## Core Value

Merchants get high-performing TikTok videos without hiring creators, filming, or understanding video production — the system reverse-engineers what already works and applies it to their product.

## Context

**Market validation:** PiiPii has run this manually for e-bike merchants. $2/video cost, $100-300/video pricing, 98% gross margin. Proven results: merchants go from ~200 views to 2,000-4,000+ per video. $4 ad spend → $600 revenue case study.

**Production pipeline (5 stages):**
1. TikTok crawl → category trend scan (TikAPI)
2. Gemini multimodal → shot-by-shot script analysis
3. Flux Pro (fal.ai) → multi-panel storyboard generation
4. Claude/automated → video prompt assembly (action sequence + voiceover timeline)
5. Kling 3.0 API (primary) / Seedance 2.0 manual (fallback) → final video generation
6. FFmpeg → segment stitching, subtitle overlay, format conversion

**Unit economics target:** <$1/video at scale (currently ~$0.93 estimated)

## Constraints

- **Tech Stack**: Next.js 14+ (App Router) + Supabase (auth, DB, storage) + BullMQ (Redis job queue) — chosen for speed-to-deploy on Vercel
- **Hosting**: Vercel (frontend + API routes) + Supabase (managed Postgres + auth + file storage) + Redis (Upstash for BullMQ)
- **API Dependencies**: Gemini API, Kling 3.0 API (快手开放平台), fal.ai (Flux Pro), TikAPI (TikTok data) — all external, rate limits apply
- **Video Gen Fallback**: Seedance 2.0 has no API — browser automation (Playwright) or manual operator intervention required
- **Budget**: Bootstrap — minimize fixed costs, use pay-per-use APIs
- **Timeline**: MVP in 2 weeks — enough to onboard first paying client
